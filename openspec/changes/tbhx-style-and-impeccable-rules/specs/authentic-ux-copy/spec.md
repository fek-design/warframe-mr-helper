## Purpose

Establishes clear, down-to-earth, player-centric copy and terminology across the entire Warframe MR Helper, prohibiting robotic AI buzzwords and removing all extraneous Framna mentions.

## ADDED Requirements

### Requirement: Ban on AI Jargon and Corporate Buzzwords
The user interface copy SHALL avoid machine-learning and corporate AI buzzwords such as "algorithmic triage", "AI-optimized", "neural synthesis", "intelligent paradigms", and "synergistic workflows".

#### Scenario: User encounters status indicators and descriptions
- **WHEN** reading item cards, header status, empty states, or drawer directives
- **THEN** all copy uses plain, direct language describing game actions (e.g. "Ready to build in Foundry", "Missing blueprints", "Available in Dojo Lab").

### Requirement: Purge of Erroneous Framna References
The application copy, tooltips, tags, and documentation SHALL NOT contain any references to "Framna".

#### Scenario: Header and brand presentation
- **WHEN** user views the header and application titles
- **THEN** the product is clearly branded as "Warframe MR Helper" (or "Warframe MR Tracker"), with zero Framna badges, labels, or watermarks.

### Requirement: Authentic Warframe Terminology
The interface SHALL use authentic Warframe in-game terminology for equipment, blueprints, components, mastery, and inventory status.

#### Scenario: Item status and acquisition guidance
- **WHEN** viewing item readiness
- **THEN** status labels reflect game concepts: "Mastered", "Unmastered", "In Inventory", "Ready to Craft", "Parts Owned", "Vaulted Relic", "Baro Ki'Teer", "Market Blueprint".
