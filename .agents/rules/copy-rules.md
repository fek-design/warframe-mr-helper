# Copy & Tone Rules: Down-to-Earth Warframe Copy

## 1. Absolute Bans

- **NO "Framna" References**: The name "Framna" was solely a transient design inspiration reference. Never include "Framna" in badges, headings, labels, documentation, or code comments.
- **NO AI Jargon & Tech Fluff**:
  - Prohibited terms: *"algorithmic triage"*, *"neural"*, *"intelligent optimization"*, *"AI-powered"*, *"curated matrix"*, *"smart paradigm"*, *"synergistic synthesis"*.
  - Write like a seasoned Warframe player talking to another player in clan chat or on Discord.

## 2. Authentic Player Terminology

Use direct, game-accurate terminology:
- Instead of "Optimal Path Triage", use **"Fastest Mastery Path"** or **"Mastery Rank Guide"**.
- Instead of "Algorithmic readiness analysis", use **"Foundry Crafting Readiness"**.
- Instead of "Tier 0 Immediate Dispatch", use **"Ready to Build"** or **"Craft in Foundry"**.
- Instead of "Component dependency acquisition", use **"Missing Parts"** or **"Blueprint Required"**.
- Instead of "Vault status active", use **"Prime Vaulted"**.
- Instead of "Dojo lab distribution vector", use **"Clan Dojo Research"**.
- Instead of "Marketplace credit unit acquisition", use **"Market Blueprint (Credits)"**.

## 3. Microcopy Principles
- **Direct & Actionable**: Every button states the exact player action ("View Blueprint", "Open Wiki", "Sync Inventory", "Upload AlecaFrame File").
- **Clear Empty & Loading States**: "No unmastered weapons found in this category", "Syncing with AlecaFrame...".
